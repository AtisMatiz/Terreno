# Working preferences

## Asking questions

- Ask a question **once**, then **wait**. Do not re-send the same or a
  near-identical question set because a reply is slow — the user may simply be
  away. No time limit applies; waiting is always correct.
- This is strict when the user invoked an interview-style skill (`/offer`,
  `/improve`, `/automate`): those skills are an explicit request to be asked and
  to answer at leisure.
- Never repeat an answer already given. If a turn resumes ("continue from where
  you left off") and a question is already outstanding, say nothing further and
  wait — do not re-ask, re-explain, or restate the prior answer.
- Prefer one consolidated round of questions over several sequential rounds.
- Be frugal with tokens generally: no restating, no re-deriving what's settled.
